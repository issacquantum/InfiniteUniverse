Dynamical System Equation

Equation

$$\frac{d\mathbf{x}}{dt}=\mathbf{F}(\mathbf{x})$$

Literal Reading

The time derivative of vector x equals F of x.

Common Reading

The current state determines the direction in which the system changes next.

Symbols

  • \(\mathbf{x}\): state vector.
  • \(t\): time.
  • \(\mathbf{F}\): rule assigning change to each state.

Meaning of the Equation

A dynamical system rule tells how the current state determines the next change. It is the general language behind motion, growth, feedback, and simulation.

Conditions and units

This is an autonomous ordinary differential equation. Each component \(F_i\) has units of \(x_i\) per unit time; different state components can have different units. Initial data are required. Local Lipschitz regularity supplies local uniqueness, but finite-time divergence can prevent global existence; a written evolution rule alone proves neither.

Worked example or interpretation

For a scalar concentration x with F(x)=−kx and constant k=0.5 s⁻¹, the state x=4 mol/m³ has instantaneous rate −2 mol/(m³·s). The equation gives the rate at that state, not a finite decrement of 2 for every step size.

Source

Driscoll and Braun, Fundamentals of Numerical Computation, initial-value problems.
