Shannon Source Coding Bound

Equation

$$ H(X)\le L < H(X)+1 $$

Literal Reading

H of X is less than or equal to L, and L is strictly less than H of X plus one.

Common Reading

An optimal prefix code can get the average bits per symbol within one bit of entropy.

Symbols

\(H(X)\): Shannon entropy of the source.

\(L\): expected number of bits per symbol used by a prefix code.

\(+1\): the finite-symbol overhead from using whole bits in a practical code.

Meaning of the Equation

Entropy sets the compression floor for expected code length under the assumed probability model. Prefix codes can approach that floor but not pass it in the ideal limit.

Conditions and units

For a discrete source with finite entropy and binary codewords, the lower bound applies to uniquely decodable codes. A prefix code exists that satisfies the strict upper bound, so an optimal code does too; an arbitrary inefficient prefix code need not. The expected length L uses the same source probabilities as H. The deterministic single-symbol case permits an empty codeword in the usual mathematical convention. Block coding can reduce the overhead per source symbol.
