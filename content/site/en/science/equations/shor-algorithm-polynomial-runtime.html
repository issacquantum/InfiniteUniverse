Shor Algorithm Polynomial Runtime

Equation

$$ \mathcal{O}\!\left((\log N)^3\right) $$

Literal Reading

Big O of the cube of the logarithm of N.

Common Reading

The asymptotic runtime scaling for Shor-type factoring in terms of the size of the integer being factored.

Symbols

\(\mathcal{O}\): big-O notation, which describes scaling behavior rather than exact runtime.

\(\log N\): the bit-length scale associated with the integer \(N\).

\((\log N)^3\): cubic growth in the logarithm of the problem size, which is polynomial in input length.

Meaning of the Equation

Gate complexity depends on implementation and arithmetic model; \(O((\log N)^3)\) is a simplified common scaling, not a hardware runtime guarantee.

Conditions and units

N is the positive integer to be factored, not the input bit count; that count is approximately \(\log_2N\). The expression describes a common elementary-arithmetic gate-count scaling for the quantum order-finding procedure and associated factoring algorithm, suppressing success-probability and implementation details. It is not a proof that no polynomial-time classical factoring algorithm exists.

Worked example or interpretation

If input bit length doubles from n to 2n, the reference cubic gate-count scale increases by a factor of eight. Doubling the integer N itself instead adds roughly one input bit. Confusing N with its bit length would turn a polynomial statement into a different claim.

Source

Peter W. Shor, Polynomial-Time Algorithms for Prime Factorization and Discrete Logarithms on a Quantum Computer.
