Polynomial Matrix-Vector Transform

Equation

$$ p(A)b $$

Literal Reading

The polynomial p evaluated at matrix A, multiplied by vector b.

Common Reading

Apply the polynomial or matrix function \(p\) to matrix \(A\), then apply the result to vector \(b\).

Symbols

\(A\): matrix or linear operator.

\(p\): polynomial or matrix function applied to \(A\).

\(b\): vector acted on by the transformed matrix.

Meaning of the Equation

This formula represents applying a polynomial of a matrix to a vector. It is a compact way to express filters, iterative methods, and some quantum-inspired linear algebra steps.

Conditions and units

For a square finite matrix, \(p(A)=\sum_{j=0}^d c_jA^j\), where \(d\) is the polynomial degree, \(c_j\) its coefficients, and \(A^0=I\). The vector dimension must match the matrix. Coefficient units must make the terms compatible; algorithms often use a dimensionless normalized matrix. A more general matrix function requires an additional definition, and this expression alone supplies neither an efficient algorithm nor an error bound.
