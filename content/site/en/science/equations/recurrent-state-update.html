Recurrent State Update

Equation

$$h_{t+1}=f(W h_t+Ux_t+b)$$

Literal Reading

h subscript t plus one equals f applied to the sum of W times h subscript t, U times x subscript t, and b.

Common Reading

This is a computational state-update model, not a literal equation of consciousness.

Symbols

  • \(h_t\): current internal state.
  • \(x_t\): current input.
  • \(W,U\): weighting matrices.
  • \(b\): bias term.
  • \(f\): nonlinear update function.

Meaning of the Equation

The hidden state acts as memory. Past inputs affect future outputs because they are folded into the state that gets updated.

Conditions and units

The subscript \(t\) is a sequence-step index, not a physical time unless the model defines one. For hidden dimension m and input dimension n, \(W\) is m by m, \(U\) m by n, and \(b\) has m components. Inputs are commonly scaled to dimensionless values; every term in the sum must use compatible units. An initial hidden state is required, and the equation does not guarantee stable dynamics or lossless long-term memory.

Worked example or interpretation

For a scalar example with f the rectified linear function, W=0.5, U=1, b=0, hidden state 2 and input 3, the next state is max(0,0.5×2+3)=4. With zero next input, the following state is 2. This selected recurrence retains part of the earlier state without storing the full input history.

Source
