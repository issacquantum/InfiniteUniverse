Deterministic Polynomial Time: P

Equation

$$P=\bigcup_{k\ge1}\mathrm{TIME}(n^k)$$

Literal reading

P equals the union, over k greater than or equal to one, of TIME of n to the k.

Conceptual reading

P contains decision problems solvable in deterministic polynomial time.

Symbols

\(P\) is a class of languages or decision problems; \(n\) is input length in the fixed encoding. \(k\) is a fixed positive integer exponent. \(\mathrm{TIME}(n^k)\) denotes deterministic time bounded asymptotically by that polynomial, up to the usual constant factors. \(\bigcup\) takes the union over exponents; \(\ge\) includes one and larger values.

Values, units and domains

Input length and step counts are dimensionless integers, not seconds. Each algorithm has a fixed exponent independent of its input length. Complexity is measured in a specified computation model.

Meaning

Membership means that some polynomial-time deterministic algorithm exists. It does not mean the algorithm is fast enough for every practical input size.

Assumptions and limits

Asymptotic worst-case decision complexity under a conventional deterministic model and reasonable encodings. P versus NP remains unresolved; this definition does not prove equality or inequality.

Example

Deciding whether an explicitly given graph has a path between two vertices can be done by graph search in polynomial time, so it is in P.

Source

Stephen A. Cook, The Complexity of Theorem-Proving Procedures (1971).
