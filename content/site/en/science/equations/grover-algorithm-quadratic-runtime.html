Grover Search Query Complexity

Equation

$$ \mathcal{O}(\sqrt{N}) $$

Literal Reading

O of square root of N.

Common Reading

The query complexity scaling of Grover's search algorithm over an unstructured search space of size \(N\).

Symbols

\(\mathcal{O}\): big-O notation, used to summarize asymptotic growth.

\(N\): the total number of candidate entries in the search space.

\(\sqrt{N}\): the quadratic improvement over a linear classical scan.

Meaning of the Equation

This is query complexity for unstructured search; it is a quadratic speedup, not an exponential one.

Conditions and units

The stated bound assumes one marked item, a coherent membership oracle, and an initial uniform superposition. With \(K\) marked items, the usual query scaling is \(O(\sqrt{N/K})\) when the success-amplification procedure is chosen appropriately. Query count is dimensionless and does not include the gates or time required to implement an oracle or load data.

Worked example or interpretation

For one marked item, increasing N by a factor of 100 increases the square-root query scale by a factor of 10. This compares asymptotic scales, not exact finite query counts or the cost of constructing the oracle.

Source

Lov K. Grover, A fast quantum mechanical algorithm for database search.
