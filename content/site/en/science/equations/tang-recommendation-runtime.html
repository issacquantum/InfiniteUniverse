Tang Recommendation Runtime

Equation

$$ \mathcal{O}(\mathrm{poly}(k)\log(mn)) $$

Literal Reading

Big O of a polynomial in k times the logarithm of the product m n.

Common Reading

Big O of a polynomial in \(k\) times the logarithm of \(mn\).

Symbols

\(\mathcal{O}\): asymptotic scaling notation.

\(\mathrm{poly}(k)\): some polynomial function of the target rank \(k\).

\(k\): target low-rank dimension.

\(m,n\): dimensions of the data matrix.

\(\log(mn)\): logarithmic dependence on total matrix size.

Meaning of the Equation

This is under sample-and-query or \(\ell_2\)-norm access assumptions, not ordinary raw data access.

Conditions and units

This is a schematic dependence on matrix dimensions and target rank with accuracy, success probability, and the theorem’s matrix-quality parameters held fixed. The full bound also depends on those parameters; hiding them is not a claim of logarithmic cost for arbitrary recommendation data. Building the sampling data structure and reading an entire output vector are separate costs. The runtime is an operation-count bound under the stated access model.

Reference

E. Tang, A quantum-inspired classical algorithm for recommendation systems.

Worked example or interpretation

With rank and all suppressed parameters fixed, doubling both matrix dimensions changes log(mn) to log(4mn), an additive logarithmic increment. This observation concerns the sampling algorithm after suitable access is available; reading all mn entries would still be a separate linear-in-input-size task.
