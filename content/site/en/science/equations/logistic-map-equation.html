Logistic Map

Equation

$$x_{n+1}=r x_n(1-x_n)$$

Literal Reading

x subscript n plus one equals r times x subscript n times the quantity one minus x subscript n.

Common Reading

The next value is produced from the current value by a simple nonlinear rule.

Symbols

  • \(x_n\): current value.
  • \(x_{n+1}\): next value.
  • \(r\): control parameter.

Meaning of the Equation

The logistic map is a simple discrete rule whose behavior can shift from stable to chaotic as the parameter changes. It shows how deterministic equations can generate unpredictability.

Conditions and units

\(n\) is a discrete iteration index; \(x_n\) and \(r\) are dimensionless. The conventional interval \(0\le x_0\le1\) stays invariant for \(0\le r\le4\). Chaotic behavior occurs only in appropriate parameter and initial-state regimes, not at every value of \(r\). This discrete map is not the continuous logistic differential equation.
