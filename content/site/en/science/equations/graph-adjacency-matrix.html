Graph Adjacency Matrix

Equation

$$A_{ij}=1\ \text{if node }i\text{ connects to node }j,\quad A_{ij}=0\ \text{otherwise}$$

Literal Reading

A subscript i j equals one if node i connects to node j, and equals zero otherwise.

Common Reading

A network can be stored as a table showing which nodes are connected.

Symbols

  • \(A_{ij}\): entry for the connection from node \(i\) to node \(j\).
  • 1: connection present.
  • 0: connection absent.

Meaning of the Equation

A matrix representation turns a network into data that algorithms can multiply, search, and compare. That makes paths, clusters, centrality, and network dynamics computable.

Conditions and units

The indices \(i,j\) label nodes; entries are dimensionless. This binary convention records the presence of an edge, not its weight or multiplicity. An undirected graph has a symmetric matrix. Diagonal entries record self-loops if permitted, and are zero for a simple loop-free graph.

Worked example or interpretation

For a simple undirected path 1-2-3, entries A₁₂,A₂₁,A₂₃,A₃₂ are one and every other entry is zero. The symmetry records undirected edges; zeros on the diagonal record the absence of self-loops.
