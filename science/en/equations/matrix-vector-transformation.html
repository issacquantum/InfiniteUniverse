Matrix-Vector Transformation

Matrix-Vector Transformation

Equation

$$\mathbf{v}^{\prime}=A\mathbf{v}$$

Literal Reading

Vector v prime equals matrix A times vector v.

Common Reading

A rule \(A\) takes one vector and produces a transformed vector.

Symbols

  • \(\mathbf{v}\): the original vector.
  • \(A\): the matrix representing the transformation.
  • \(\mathbf{v}^{\prime}\): the vector after the transformation.

Meaning of the Equation

A matrix-vector product combines input components into new output components. It is the basic linear operation behind rotations, projections, networks, and numerical algorithms.

Conditions and units

For an \(m\)-by-\(n\) matrix, the input has \(n\) components and the output \(m\); the prime labels the transformed vector, not a derivative. In components, \(v_i^{\prime}=\sum_{j=1}^n A_{ij}v_j\). Entry units must convert each input component into the corresponding output units. Only special matrices represent rotations; a general matrix need not preserve lengths, angles, or information.

Worked example or interpretation

The dimensionless matrix with rows (0,−1) and (1,0) sends vector (1,0) to (0,1), a quarter-turn counterclockwise in the Cartesian plane. A different matrix, such as diagonal entries 2 and 1, stretches one component and is not a rotation.

Source

Gilbert Strang, MIT 18.06 Linear Algebra.
