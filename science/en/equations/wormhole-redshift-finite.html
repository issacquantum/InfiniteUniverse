Finite Redshift Condition

Finite Redshift Condition

Equation

$$ |\Phi(r)|<\infty $$

Literal Reading

The absolute value of phi of r is finite.

Common Reading

A finite redshift function keeps the static lapse factor \(e^{2\Phi(r)}\) nonzero and finite along the proposed passage.

Symbols

\(\Phi(r)\): redshift function in the Morris-Thorne metric.

\(e^{2\Phi(r)}\): factor controlling gravitational time dilation in the metric.

Meaning of the Equation

For a traversable wormhole model, the redshift function must stay finite so no horizon blocks passage through the throat. It is a geometry condition, not a travel guarantee.

Conditions and units

\(\Phi\) is dimensionless and r an areal radius. In this static ansatz \(\Phi\to-\infty\) makes the lapse vanish; a positive divergence is not automatically an event horizon. A global horizon statement requires the full geometry. Finite values alone do not control derivatives, curvature, tidal effects, or the matter supporting the wormhole.

Worked example or interpretation

Choosing Φ(r)=0 gives lapse factor exp(2Φ)=1 throughout the chosen domain, so this factor creates no static redshift horizon. The shape function, curvature and supporting stress-energy still need independent checks.

Source

Morris and Thorne (1988), Wormholes in spacetime and their use for interstellar travel (publication page).
